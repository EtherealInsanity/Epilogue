[ EPUB CREATOR & EDITOR ]

Author, Edit & Package Retail-Ready EPUBs

Epilogue Studio is a complete EPUB authoring suite built right into your reading app. Create new publications from scratch or edit books from your existing library with desktop-grade precision.

✍️

Tri-Mode Chapter Editor

Write and edit chapters the way you want. Seamlessly toggle between Visual WYSIWYG, clean Markdown, and raw XHTML/CSS Source Inspector with real-time word counting and formatting toolbars.

WYSIWYG Visual Editor ⇄ Markdown Fast Draft ⇄ Raw XHTML/CSS Inspector
🛡️

Pre-Flight Linter & Auto-Fix

Real-time validation engine detects unclosed XHTML tags, unescaped ampersands, missing Dublin Core UUIDs, and empty chapters with 1-click automatic syntax repair.

📚

Professional Genre Templates

Instant project scaffolding with pre-tuned typography: Classic Novels (drop caps, scene breaks), Light Novels / Fantasy (Star Stream status cards), and Non-Fiction (hierarchical headings, callouts).

📑

Drag-and-Drop Spine Hierarchy

Reorder chapters effortlessly using tactile drag-and-drop handles. Duplicate existing chapters, rename titles, and inspect chapter-by-chapter word counts at a glance.

📦

EPUB 3.3 + EPUB 2 NCX Compiler

Direct packaging generates byte-exact uncompressed mimetype at offset 30, dual nav.xhtml and toc.ncx, passing W3C epubcheck for Kindle, Apple Books, and Kobo.

⚡

Non-Destructive Library Editing

Import any book directly from your Archive library into Studio with a single tap. Fix formatting, adjust metadata, add illustrations, or recompile into standard .epub or .kepub.epub without modifying original files.

Instead of parsing hundreds of chapters synchronously on opening, Epilogue loads book metadata and only parses an initial sliding window (±2 chapters). Background prefetching resolves adjacent chapters smoothly as you read.
